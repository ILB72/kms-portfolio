# 경력기술서 — 김민석

Aleph 과정(2026-10-20~) 수행 과제 중 6개를 골랐습니다. 자기조절력·대인관계력·자기동기력이 각각 2개씩 드러나도록 배정했습니다.

| 과제 | 해당 능력 | 상황 · 행동 · 결과 |
|---|---|---|
| T01 나를 소개하는 한 페이지 (10-21 ~ 10-23) | 자기조절력 | **상황** 소개 페이지를 과제 기준에 맞게 만들어야 했다. **행동** 읽는 대상과 공개 범위를 먼저 정하고, AI 제안은 수용·거부 기준을 기록해 가며 선택했다. 두 해상도에서 첫 화면을 점검해 접근성·콘솔 결함 3건(파비콘 404, main 태그 누락, 명암 대비)을 찾아 고쳤다. **결과** Lighthouse 접근성 92점에서 100점으로 개선, 강사 상담 피드백을 반영해 최종 완성. |
| T04 오늘의 진짜 정보판 (10-26 ~ 11-02) | 자기동기력 | **상황** 공개 API 기온 정보판에서 데이터가 실패하는 상황을 다뤄야 했다. **행동** 주어진 스키마(9개 필드)를 지키면서 실패 5종 재생, 같은 날짜 갱신, 어제 대비를 구현했다. 요구 밖으로 시간별 예보와 과거 7일 조회를 어디까지 넣을지 스스로 정해 추가했고, 답안지처럼 보이는 화면을 제품형으로 다시 배치했다. **결과** 최신 커밋으로 재제출했다. |
| T05 대화가 끊겨도 이어지는 프로젝트 (10-27) | 대인관계력 | **상황** 한 AI가 만든 저장소를 다른 AI가 이어받아 개선하는 실험이었다. **행동** 검사 10개를 작업 전에 고정하고, 작업 내용과 규칙을 HANDOFF.md에 적어 AI 두 개에게 각각 넘겼다. AI의 "코드상 통과"라는 말은 인정하지 않고 콘솔로 직접 검증했으며, 구버전 캐시로 실패한 항목은 기록을 남기고 재검증했다. **결과** 한 쪽 8/10, 다른 쪽 10/10 통과. 인수인계 문서의 질이 결과를 갈랐음을 확인했다. |
| T06 플랜두씨 다이어리 1 (10-28) | 자기동기력 | **상황** 계획·할 일·실행·돌아보기를 담는 풀스택 앱이 필요했다. **행동** 데이터 구조(테이블 4개)를 직접 기획하고, 중복 완료를 막는 UNIQUE 키와 한국 시간 기준 지연 집계를 구현했다. 처음 다루는 DB·배포 서비스를 직접 골라 연결했고, 제안받은 테마는 거부했다. **결과** 새 시크릿 창에서 로그인 없이 데이터가 유지되는 것을 확인했다. |
| T08 내 소개 페이지에 패스키 달기 (11-03) | 자기조절력 | **상황** 비밀번호 없이 나만 들어가는 비공개 영역이 필요했고, 교육장 컴퓨터에 블루투스가 없어 아이폰 패스키를 테스트할 수 없었다. **행동** 막힌 채로 포기하지 않고 바람을 쐰 뒤, 테스트의 본질(패스키 여러 개 중 하나를 잃어도 접속)로 질문을 바꿔 아이폰에서 직접 확인했다. 테스트용으로 풀어 둔 설정은 원복하고 못 막은 한계는 기록했다. **결과** 삭제 후 로그인, 삭제한 패스키 선택 불가, 계정 2개 교차 검증을 확인했다. |
| T10 AI와 함께 쓰는 첫 논문 (11-05) | 대인관계력 | **상황** 공개 데이터로 IoT 기기 분류를 재현해 읽는 사람에게 결과를 전달해야 했다. **행동** 5종 기기 균등 샘플(12,816개)로 RandomForest를 학습해 98.19%를 얻고, 별도 PC 트래픽 697 flow로 외부 검증했다. 392개(56.2%)가 카메라로 분류된 결과는 분류 대상에 없는 기기를 강제로 분류한 한계로 설명해, 읽는 사람이 결과를 오해하지 않게 했다. **결과** 논문과 원자료를 분리해 제출(용량 제한 대응). |

## 사실 확인 필요
1. 능력 배정은 작업일지의 기재(T04·T08·T10은 자기조절력)에서 균형을 위해 바꾼 것입니다. T04는 자기동기력, T10은 대인관계력(독자에게 한계를 전달)으로 옮겼습니다. 이 해석이 맞는지 본인 판단.
2. T01 "강사 상담 피드백 반영"은 일지 기록입니다. 강사 이름·기관은 쓰지 않았음.
3. T05 "인수인계 문서의 질이 결과를 갈랐다"는 8/10 대 10/10 결과로부터의 해석입니다. 단정이 과하면 문장을 줄일 것.
4. T10 "분류 대상에 없는 기기를 강제로 분류한 한계" — 일지 L908, L914 근거. 논문 본문 표현과 일치하는지 대조.
5. 일지에서 T04 재제출·T08 제출은 "대기" 상태로 적혀 있음. 제출 현황 대시보드의 현재 상태와 일치하는지.
