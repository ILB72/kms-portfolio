# 경력기술서 — 김민석

Aleph 과정(2026-10-20~) 수행 과제 중 6개를 골랐습니다. 세 능력이 모두 드러나도록 배정했습니다.

| 과제 | 해당 능력 | 상황 · 행동 · 결과 |
|---|---|---|
| T01 나를 소개하는 한 페이지 (10-21 ~ 10-23) | 자기조절력 | **상황** 소개 페이지를 과제 기준에 맞게 만들어야 했다. **행동** 읽는 대상과 공개 범위를 먼저 정하고, AI 제안은 수용·거부 기준을 기록해 가며 선택했다. 두 해상도에서 첫 화면을 점검해 접근성·콘솔 결함 3건(파비콘 404, main 태그 누락, 명암 대비)을 찾아 고쳤다. **결과** Lighthouse 접근성 92점에서 100점으로 개선, 강사 상담 피드백을 반영해 최종 완성. |
| T02 내가 설계한 미니게임 (10-23 ~ 10-28) | 대인관계력 | **상황** 2레인 리듬 게임(Rhythm Dodge)을 Canvas로 설계·구현하고 과제 기준 C01~C31 검증을 마친 뒤, 개선 단계에서 다른 사람의 테스트와 의견이 필요했다. **행동** 10월 29일 다른 사람들이 이 게임을 재미있게 즐기려면 어떤 기능이 필요한지를 먼저 생각하고, 다른 사람에게 플레이를 보여주거나 직접 해 보게 하면서 어떻게 고쳐 갈지 말하고 의견을 들었다. **결과** 11월 5일 피드백에서 미처 생각하지 못한 시스템 허점을 지적받았고, 11월 6일에는 아이템 기능 추가 등 생각하지 못한 의견을 받았다. 두 의견 모두 리추얼 감사 항목에 기록했다. |
| T04 오늘의 진짜 정보판 (10-26 ~ 11-02) | 자기동기력 | **상황** 공개 API 기온 정보판에서 데이터가 실패하는 상황을 다뤄야 했다. **행동** 주어진 스키마(9개 필드)를 지키면서 실패 5종 재생, 같은 날짜 갱신, 어제 대비를 구현했다. 요구 밖으로 시간별 예보와 과거 7일 조회를 어디까지 넣을지 스스로 정해 추가했고, 답안지처럼 보이는 화면을 제품형으로 다시 배치했다. **결과** 최신 커밋으로 재제출했다. |
| T06 플랜두씨 다이어리 1 (10-28) | 자기동기력 | **상황** 계획·할 일·실행·돌아보기를 담는 풀스택 앱이 필요했다. **행동** 데이터 구조(테이블 4개)를 직접 기획하고, 중복 완료를 막는 UNIQUE 키와 한국 시간 기준 지연 집계를 구현했다. 처음 다루는 DB·배포 서비스를 직접 골라 연결했고, 제안받은 테마는 거부했다. **결과** 새 시크릿 창에서 로그인 없이 데이터가 유지되는 것을 확인했다. |
| T08 내 소개 페이지에 패스키 달기 (11-03) | 자기조절력 | **상황** 비밀번호 없이 나만 들어가는 비공개 영역이 필요했고, 교육장 컴퓨터에 블루투스가 없어 아이폰 패스키를 테스트할 수 없었다. **행동** 막힌 채로 포기하지 않고 바람을 쐰 뒤, 테스트의 본질(패스키 여러 개 중 하나를 잃어도 접속)로 질문을 바꿔 아이폰에서 직접 확인했다. 테스트용으로 풀어 둔 설정은 원복하고 못 막은 한계는 기록했다. **결과** 삭제 후 로그인, 삭제한 패스키 선택 불가, 계정 2개 교차 검증을 확인했다. |
| T10 AI와 함께 쓰는 첫 논문 (11-05) | 자기조절력 | **상황** 공개 데이터로 IoT 기기 분류를 재현하고, 학습에 없는 기기(PC 트래픽)에 적용했을 때의 분류 경향을 분석해야 했다. **행동** 5종 기기 균등 샘플(12,816개)로 RandomForest를 학습해 98.19%를 얻고, 별도 PC 트래픽 697 flow로 외부 검증했다. 392개(56.2%)가 카메라로 분류된 결과는 분류 대상에 없는 기기를 강제로 분류한 결과로 분석했다. 원인을 대용량 전송 패턴의 유사성으로 추론하되 설명 가능 AI 분석이 없어 인과를 단정하지 않고 한계로 명시했다. **결과** 논문과 원자료를 분리해 제출(용량 제한 대응). |

## 사실 확인 필요
1. [확정(세션 의견 일치)] T04는 자기동기력. 근거: 일지 L483·L486·L487·L492(11/02 과제 4 추가 개선), "내가 먼저 제안" L447·L462·L496. 자기조절력 근거 L464·L467~469는 보조(L466~469는 "AI 제안을 따르지 않은 일" 블록). 작업일지 원문의 분류(자기조절력)와는 다르게 배정했음.
2. T01 "강사 상담 피드백 반영"은 일지 기록입니다. 강사 이름·기관은 쓰지 않았음.
3. T02 근거: 상황 일지 L140·L151·리추얼 L201, 행동 리추얼 L190·L193(10/29), 결과 리추얼 L340·L344(11/05)·L369·L374(11/06). 사람 소통 근거는 리추얼뿐이고 작업일지 T02 항목에는 없음. [확정] 11/06 아이템 기능 의견은 T02에 대한 것(사용자 확인). 11/05·11/09의 동료 감사 문장은 누가 누구에게 한 말인지 모호해 쓰지 않았음.
4. T10 "분류 대상에 없는 기기를 강제로 분류한 결과"·"인과를 단정하지 않고 한계로 명시" — 일지 L892, L914 근거. 논문 본문 표현과 일치하는지 대조.
