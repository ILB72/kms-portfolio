# 제출문 초안 — 과제 12 (마지막 A)

## AI와 나의 판단 세 줄
① **AI에게 맡긴 일**: 소설·기록에서 사이트 이야기와 지원 문서 3종의 초안 작성, 갱신 프로그램과 사이트 코드 작성, 수치 재집계와 후보 문장 생성 틀 작성.
② **내가 직접 판단한 일**: 한 줄 소개 선택, 공개 수위(외부평가 연도 공개로 변경, 자격증 공개), 공개 연락 수단 1개 결정, 소설 속 각색·허구·가족사·기관명·강사 이야기 제외, 대표작 선정, 갱신 후보 중 반영할 문장 승인, 초안의 사실 대조.
③ **AI 제안을 따르지 않은 일**: 계획 단계에서 제시된 한 줄 소개 후보 중 외부평가 시기(연·월)가 들어간 안을 쓰지 않고, 시기가 없는 "실패한 날의 기록을 다음 시도의 설계도로 바꾸는 사람"을 골랐다. 외부평가 연도는 처음에 비공개로 정했다가 이후 공개로 변경했다(사이트·문서에 2025년 12월 불합격, 2026년 3월 합격으로 표기).

## 짧은 확인 방법
- 사이트 URL: https://(사이트 URL 자리표시자)
- 이름과 한 줄 소개: 첫 화면 맨 위
- 이야기(고난 → 다시 일어선 날 → 더 나아진 현재): 첫 화면 아래 "이야기" 영역, 단락마다 날짜로 시작
- 수치와 출처: "수치" 영역 (내 출석 기록 / 리추얼 기록 / 내 제출 현황)
- 대표작: "대표작" 영역 — 10번 논문 PDF, 13번 앱 자리
- 문서: 이력서·자기소개서·경력기술서 (`docs/`, 첫 화면에는 이력서 링크)
- ZIP 안: `updater/update.py`, `README.md`(실행 3단계), `output/`(최종 실행 결과, 2회 비교 `run_compare.txt`), `approved.json`, `docs/`

## 사실 확인 필요
1. ③의 "따르지 않은 일"은 계획서 §2·§12(한 줄 소개 후보 3개 중 후보 2 선택; 연도 비공개 결정은 이후 공개로 변경됨) 기록으로 작성했습니다. 실제로 본인이 AI 제안을 거부한 다른 사례가 있으면 바꾸거나 추가하세요.
2. ①의 "갱신 프로그램과 사이트 코드 작성"은 계획서의 세션 분담 기준입니다. 실제로 AI가 한 범위와 본인이 직접 한 범위를 확인해 수정하세요.
3. BRA-C05의 "13주 기록"은 실제 기록 기간이 약 4주(10/20~11/16)라는 계획서 §3 판단을 따랐습니다. 사이트 문구와 일치하는지 확인.
4. 짧은 확인 방법의 영역 이름(이야기·수치·대표작)은 사이트 구현 세션이 정한 제목과 같아야 합니다.
