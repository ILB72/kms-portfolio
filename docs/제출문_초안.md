# 제출문 초안 — 과제 12 (마지막 A)

## AI와 나의 판단 세 줄
① **AI에게 맡긴 일**: 역할별로 나눠 맡겼다. 글(S1): 소설·작업일지·리추얼 기록을 읽고 사이트 이야기 본문과 지원 문서(이력서·자기소개서·경력기술서)·제출문 초안 작성. 갱신 프로그램(S2): 수치 재집계와 능력별 후보 문장 생성 코드, README, 두 번 실행 비교. 사이트(S3): 사이트 화면 코드 작성과 배포 작업.
② **내가 직접 판단한 일**: 이름과 공개 이메일 1개 결정, Vercel 배포 선택, 한 줄 소개 선택(후보 2번), 외부평가 연도 공개 결정, 자격증 공개, 사실 확인 답변(실제 기출 문제집이 없었다는 점, 3월 17일 합격 발표, 재학습 방식, 12월 24일 집에 돌아가자마자 공책을 폈다는 점), 동료 검증 장면 삭제, 공책 PDF 제공.
③ **AI 제안을 따르지 않은 일** (작업일지 형식: 무엇을 / AI 제안·초안 / 내가 거부·수정한 이유)
- 사실 정정: 12월 24일 장면에서 AI 초안은 "그날 밤 공책을 폈다", "기출 같은 정보가 거의 없었다"고 썼으나, "집에 돌아가자마자 공책을 폈다", "출제 범위와 예시 문제만 있고 실제 기출 문제집은 없었다"로 고쳤다. 실제 기억과 맞지 않는 표현이어서.
- 허구 가능성 제거: AI 초안의 "동료 2명에게 읽혀 검증" 장면을 삭제하고 2026-11-11 리추얼 기록(동료 작품을 평가할 때 만든 의도를 먼저 물음)으로 대체했다. 내 기록에 근거가 있는 장면만 남기려고.
- 디자인·공개 판단: AI가 제안한 공책 사진과 소개 페이지 캡처 사용은 화면이 지저분하고 개인 정보성이 있다고 판단해 제외했다.

## 사용자 확인 필요
### ③ "AI 제안을 따르지 않은 일"
1. 작업일지 기준(AI가 제안·작성한 내용 중 사실이나 본인 판단에 맞지 않아 거부·수정한 사례)으로 3건을 채웠습니다. 사용자 최종 확인 필요.
2. 일지 기준 근거: `input/과제 작업 일지.txt` L465~470, L848~864, L938~960. 위 3건의 "공책 사진·소개 페이지 캡처 제외" 사유(지저분함, 개인 정보성)는 전달받은 사용자 판단 그대로이며 이 세션에서 직접 확인하지 않았습니다.
3. 한 줄 소개 후보 중 2번 선택은 제안 중 선택이라 넣지 않았습니다.

### 그 밖의 확인
