# updater — 포트폴리오 수치·문단 후보 자동 갱신

새 기록(리추얼·출석·제출 현황)으로 사이트 수치(`metrics.json`)와 세 능력(자기조절력·대인관계력·자기동기력)별 문단 후보(`candidates.md`)를 다시 만듭니다.
**Python 3 표준 라이브러리만** 씁니다. AI 호출, 난수, 현재시각을 쓰지 않으므로 같은 입력이면 출력이 바이트 단위로 같습니다.

## 실행 3단계
1. Python 3.8 이상을 준비합니다(설치할 패키지 없음).
2. 저장소 루트에서 실행합니다.
   ```
   python updater/update.py --input updater/sample_input --out updater/output
   ```
3. `updater/output/candidates.md`를 읽고, 사이트에 쓸 후보 id를 입력 폴더의 `approved.json`에 넣은 뒤 2단계를 다시 실행합니다. 승인한 후보만 `site_data.json`에 들어갑니다.

테스트: `python -m unittest discover -s updater/tests`

## 환경변수
필요 없음. API 키도 쓰지 않습니다.

## 입력 폴더 형식 (`--input`)
| 파일 | 형식 |
|---|---|
| `ritual-history-*.txt` | 리추얼 기록 내보내기. `## YYYY-MM-DD`(날짜), `[아침]`/`[마무리]`(구역), `- 항목: 값`(줄). 파일이 여러 개면 이름순으로 읽고, 같은 날짜는 뒤 파일이 이깁니다. |
| `attendance.json` | `{"as_of": "2026-11-16", "training_days": 20, "present": 19, "absent": 0, "unconfirmed_days": 1}` |
| `submissions.json` | `{"submissions": [{"task": "T01", "date": "2026-10-22"}, ...]}` (제출 1건이 1줄) |
| `approved.json` | `{"approved": ["<후보 id>", ...]}` (없으면 승인 0건) |

## 출력 폴더 (`--out`)
| 파일 | 내용 |
|---|---|
| `metrics.json` | 기록일 수, 아침/마무리 횟수, 출석 훈련일·출석·결석·출석률, 제출 횟수·과제 수·재제출 수. 각 수치에 `source`("리추얼 기록"/"내 출석 기록"/"내 제출 현황")가 반드시 붙습니다. |
| `candidates.md` | 능력별 후보. 후보마다 id(`날짜_항목_해시8자`), 문장, 근거(날짜·구역·항목명). `[x]`는 승인됨. |
| `site_data.json` | `metrics` + 승인된 후보만 담은 `paragraphs`. 사이트가 읽는 파일입니다. |
| `warnings.txt` | 제외·경고 목록. 값은 적지 않고 id나 파일·줄 번호만 적습니다. |
| `run_compare.txt` | (이 저장소의 `output/`에만) 같은 입력 2회 실행의 SHA-256 비교 기록. |

## 규칙
- **분류**: `update.py`의 `KEYWORDS` 사전에서 일치하는 키워드 수가 가장 많은 능력으로 분류(동점이면 자기조절력→대인관계력→자기동기력 순). 어느 것에도 안 맞으면 후보에서 빠지고 개수만 셉니다.
- **입력 단계 제외**: `동료 N에게 말한 장점`, `동료 N가 말해 준 내 장점`, `동료 N가 나눈 감사`, `감사일기` 칸은 읽지 않습니다. `호흡`, `강점 행동`은 수치 성격이라 후보로 쓰지 않습니다.
- **후보 제외 + 경고**: `…님` 형태 이름이나 `(이름 가림)` 표기가 남은 문장, 가족·건강·학비 등 민감 주제 키워드(`update.py`의 `SENSITIVE` 목록)가 있는 문장.
- **비밀값 경고**: API 키·토큰·비밀번호 패턴이 입력 파일에 있으면 파일·줄 번호만 경고합니다.
- 입력 원문을 출력 폴더에 통째로 복사하지 않습니다. 실제 기록(`input/`)으로 실행한 결과는 저장소 밖 폴더에 두세요.
- `sample_input/`은 공개용 **합성 데이터**입니다(실제 리추얼의 구조·날짜만 따름, 문장은 예시). 출석·제출 수치는 실제 값입니다.
